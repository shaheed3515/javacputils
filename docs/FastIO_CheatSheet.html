JavaCPUtils: FastIO API Cheat Sheet

High-speed Input & Output Reference for Competitive Programming.

*Up to 10x faster reading than Scanner, 30x faster writing than System.out.println.*

1. Quick Start: The 10-Second Contest Template

import cp.*;

public class Solution {
    public static void main(String[] shd) {
        int t = FastIO.nextInt();
        while (t-- > 0) {
            int n = FastIO.nextInt();
            int[] arr = FastIO.nextIntArray(n);     // Read array in 1 line!
            IntPair edge = FastIO.nextIntPair();   // Read pair in 1 line!

            // Solve problem...

            FastIO.println("YES");
            FastIO.println(arr);                   // Prints 10 20 30 with newline!
            FastIO.println(edge);                  // Prints (u, v) with newline!
        }
        FastIO.flush(); // CRITICAL: Always flush at the end of main()!
    }
}

2. Complete Fast Input Methods (FastIO / FastScanner)

OperationMethod SignatureReturn TypeDescription
Check AvailableFastIO.hasNext()booleanReturns true if there are more non-whitespace tokens.
Read String TokenFastIO.next()StringReads next whitespace-delimited word.
Read Entire LineFastIO.nextLine()StringReads remainder of line until \n.
Read 32-bit IntegerFastIO.nextInt()intReads next integer. Handles negative signs.
Read 64-bit LongFastIO.nextLong()longReads next 64-bit integer up to $10^{18}$.
Read DecimalFastIO.nextDouble()doubleReads next floating-point number.
Read Integer ArrayFastIO.nextIntArray(n)int[]Reads n space/newline-separated ints into an array.
Read Long ArrayFastIO.nextLongArray(n)long[]Reads n space/newline-separated longs into an array.
Read IntPairFastIO.nextIntPair()IntPairReads next two ints directly into an IntPair.
Read LongPairFastIO.nextLongPair()LongPairReads next two longs directly into a LongPair.

3. Complete Fast Output Methods (FastIO / FastWriter)

*All println() methods automatically append a newline (\n). No manual \n needed!*

OperationMethod SignatureTrailing Newline?Description
Print ValueFastIO.print(val)❌ NoWrites int, long, double, char, String, or Object.
Print with NewlineFastIO.println(val)✅ YesWrites value followed by \n.
Print Blank LineFastIO.println()✅ YesWrites an empty line (\n).
Print Array (1 Line)FastIO.println(int[] a)✅ YesPrints elements separated by space + \n at the end.
Print Array InlineFastIO.print(int[] a)❌ NoPrints elements separated by space without trailing \n.
Print Long ArrayFastIO.println(long[] a)✅ YesPrints long array space-separated + \n at the end.
Print PairFastIO.println(pair)✅ YesPrints (first, second) followed by \n.
Flush BufferFastIO.flush()—MANDATORY: Dumps 64KB RAM buffer to terminal/judge.

4. Key Rules to Remember in Live Contests ⚠️

  • Always Call FastIO.flush() at the end of main():

    • Because FastWriter stores output in high-speed RAM, if you forget FastIO.flush(), your output may stay trapped in memory and Codeforces will show Wrong Answer on empty output!

  • Online Judge Submissions:

    • Run bundle Solution.java before uploading to Codeforces, LeetCode, CSES, or HackerRank.
